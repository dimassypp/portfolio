01 - OVERVIEW

What is
BookPort?

A blockchain-based e-commerce platform for imported books, developed as a full-stack web application for international book commerce.

02 — PROBLEM

The challenge
behind it.

Problem

Imported-book commerce requires product discovery, ordering, and transaction flows to work together coherently. The project also explores blockchain integration in an e-commerce application.

03 - SOLUTION

Turning the
problem around.

Solution

BookPort brings browsing and commerce into one web application while integrating blockchain-related functionality into the overall system.
